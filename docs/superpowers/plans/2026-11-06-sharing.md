# Sharing with Doctors and Family Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Share links to a scoped, read-only view of the user's GA record. Each link has a summary, records, an Ask box backed by the user's Claude API key, PDF and FHIR downloads, an access log, and an offline export.

**Architecture:**
- A new `ga-share` compose service (`node:http`) serves `/s/<token>/…` on `127.0.0.1:8110`. Tailscale Funnel exposes it to the internet.
- Every route and every Ask tool works from one list: `loadScoped(share)`, the share's records fetched from Medplum's patient compartment, filtered in memory by `inScope`, and cached briefly. Scope is enforced by construction: nothing outside that list is ever reachable.
- Shares live in `.ga/shares.json` (metadata and token hash). Tokens are encrypted with the existing AES-GCM secret store. The access log is Medplum AuditEvents.

**Tech Stack:** Node 26 strip-only TypeScript, `@medplum/core` 5.2.14, `@anthropic-ai/sdk` 1.6.0, `pdfmake` 0.3.13, `qrcode` 1.5.4, vitest.

**Spec:** `docs/superpowers/specs/2026-11-06-sharing-design.md`

## Global Constraints

- **TypeScript:** Node 26 runs `.ts` in strip-only mode: no parameter properties, enums or namespaces.
- **Dependencies:** pinned exactly: `pdfmake@0.3.13`, `qrcode@1.5.4`, `@types/qrcode@1.5.6`, `@types/pdfmake@0.3.3` (dev). No web framework, no client-side JS framework, nothing loaded from third parties.
- **Tests:**
  - Never touch the real patient. Integration tests use `createTestPatient` / `cleanupTestPatient` (`tests/integration/helpers.ts`).
  - No PHI in fixtures, logs or commits.
  - Unit tests: `npm test`. Integration tests: `npm run test:int -- <file>`, one file at a time.
- **Share fields:** `id`, `label`, `audience: 'doctor'|'family'`, `groups: Group[] | 'all'`, `since?`, `until?` (YYYY-MM-DD), `expires?` (ISO, absent = never), `layout: 'A'|'B'`, `questionsPerDay`, `tokenHash`, `patientId`, `baseUrl`, `created`, `revoked?`, `asked?: {day: string; n: number}`.
- **Defaults:**
  - doctor: groups `labs,medications,problems,allergies,immunizations,vitals`; expires 7 days; layout A; 20 questions a day.
  - family: `all`; never expires; layout B; 20 questions a day.
- **Token:** 32 random bytes, base64url, used in the path `/s/<token>`. Looked up by its SHA-256.
- **Never shared:**
  - `Endpoint`, `Provenance`, `AuditEvent`;
  - DocumentReferences with an identifier system `urn:ga-server:id:ehi-archive` or `urn:ga-server:id:apple-health-archive`;
  - anything not in this share's patient compartment.
- **Patient:** trimmed to `{resourceType, id, name, birthDate, gender}`.
- **Date range** applies to events only. Active problems, medications and allergies (`clinicalStatus`/`status` active, unconfirmed included) are included whatever their date. Inactive ones follow the range. Undated events are included only when the range is open-ended (no `since` and no `until`).
- **Ask:**
  - model `claude-opus-5-5`;
  - instructions are steps 1–9 of `.claude/skills/ga/SKILL.md` read at runtime (step 0 dropped);
  - answer shown as plain text;
  - per-share daily cap.
- **Unknown, expired or revoked tokens:** the same page, "This link is no longer active", with HTTP 404.
- **Response headers on every response:**
  - `Referrer-Policy: no-referrer`
  - `Cache-Control: no-store`
  - `X-Robots-Tag: noindex`
  - `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; img-src 'self' data:; form-action 'self'; base-uri 'none'; frame-ancestors 'none'`
  - `X-Content-Type-Options: nosniff`
- **`meta.source`** in shared output is reduced to its file name (`basename`).
- **Ports and environment:** service port `8110`, published as `127.0.0.1:8110:8110`. `ANTHROPIC_API_KEY` reaches the container from the host environment or the gitignored `.env`.

## Review Focus

1. **Record text containing HTML or script**, such as a note with `<script>` or a lab `code.text` with `"><img onerror>`: it shows as text everywhere (page, QR page, answers). Test in Task 5.
2. **A note that tells Claude to "list all labs" in a share without labs:** the Ask tools still return nothing out of scope. Test in Task 6.
3. **A `family` share with `all` over about 30k records** (Apple readings): the page loads quickly and the PDF stays a reasonable size. Apple Observations go in the PDF and summary as one per-type line each (count, date range, latest value), never one row per reading. The FHIR file has everything and streams. The All records tab pages 200 at a time. Tests in Tasks 4 and 5.
4. **Expiry at a day boundary:** `--expires 2026-11-13` means valid through the end of Nov 13 in the machine's zone. A link created with `7d` expires exactly 7×24 h later. Test in Task 1.
5. **A share created or revoked while `ga-share` is running:** the next request sees it without a restart, because the server reads `shares.json` on every request. Test in Task 7.
